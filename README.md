🇦🇱 AlbaniaGuides – Discover Albania

AlbaniaGuides është një platformë web interaktive e krijuar për të promovuar turizmin shqiptar dhe për t'u mundësuar vizitorëve të zbulojnë destinacionet më të bukura të Shqipërisë. Platforma synon të lidhë turistët me eksperiencat turistike, guidat dhe aktivitetet që ofron vendi ynë.

Projekti ofron një ndërfaqe moderne, responsive dhe intuitive, duke e bërë më të lehtë eksplorimin e destinacioneve dhe rezervimin e eksperiencave turistike.

🌍 Features
Tourist Destinations: Eksplorimi i destinacioneve turistike në Shqipëri.
Interactive Map: Hartë interaktive për vizualizimin e pikave turistike.
Booking System: Mundësia për të rezervuar guida dhe paketa turistike.
Destination Categories: Kategorizimi i aktiviteteve si Hiking, Beaches dhe History.
Destination Details: Informacione për destinacionet, itineraret, çmimet dhe fotografitë.
Responsive Design: Përshtatje për desktop, tablet dhe pajisje mobile.
Navigation System: Navigim dinamik dhe menu e përshtatshme për pajisjet mobile.

⚙️ Installation and Setup

Follow these steps to run the project locally.

1. Clone the repository
bash
git clone https://github.com/IrisMalaj/Project1.git

2. Navigate to the project directory
bash
cd Project1

3. Create a virtual environment
bash
python -m venv venv

4. Activate the virtual environment

Windows:

bash
venv\Scripts\activate


Linux / macOS:

bash
source venv/bin/activate

5. Install dependencies

Install Django and any additional dependencies required by the project:

bash
pip install django

6. Apply database migrations
bash
python manage.py migrate

7. Run the development server
bash
python manage.py runserver


Open your browser and visit:

text
http://127.0.0.1:8000/

🎯 Project Objectives

The main objective of AlbaniaGuides is to contribute to the digital promotion of Albanian tourism by:

Making tourist destinations easier to discover.
Providing accessible information about tourist activities.
Simplifying the booking process for tourist experiences.
Promoting Albania's natural, historical and cultural attractions.
Improving the overall user experience through modern web technologies.
